📊 Local Database

This application uses a local database with 600MB+ of compressed dork data from multiple sources:

  • Google Hacking Database (GHDB) - Official exploit-db collection
  • TrixSec DorkHub - Community-driven repository

⚠️ Performance Notice

Due to GitHub's file size restrictions, the entire database loads into your browser's memory:

  • Initial load may take 10-30 seconds
  • Uses approximately 300-600MB of RAM
  • Provides instant search after loading
  • Works completely offline once loaded

🚀 Features

  • Visual dork query builder with drag & drop
  • Browse 100,000+ dorks from multiple sources
  • Filter by category, source, and keywords
  • Direct search engine integration
